# VARIABLE
es un espacio reservado en la memoria del computador  al que le pones un nombre
y sirve para guardar información que puede  cambiar O modificar mientras el programa
funciona como una cajita le pones una etiqueta con el nombre y dentro guardas un valor
que puedes revisar cambiar o borrar cuando quieras

Guardar datos que se necesitan usar varias veces edad precios cantidad
Almacenar resultados de operaciones o cálculos
Recordar información que ingresa el usuario
Hacer que tu programa sea flexible si cambias el valor de la variable todo el código se utiliza solo
