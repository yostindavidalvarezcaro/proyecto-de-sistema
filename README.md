# VARIABLE
es un espacio reservado en la memoria del computador  al que le pones un nombre
y sirve para guardar información que puede  cambiar O modificar mientras el programa
funciona como una cajita le pones una etiqueta con el nombre y dentro guardas un valor
que puedes revisar cambiar o borrar cuando quieras
        PARA QUE SIRVE
- Guardar datos que se necesitan usar varias veces edad precios cantidad
- Almacenar resultados de operaciones o cálculos 
- Recordar información que ingresa el usuario
- Hacer que tu programa sea flexible si cambias el valor de la variable todo el código se utiliza solo

             CUALES SON SUS FUNCIONES
  -   Para que una variable cumpla su trabajo pasa por tres etapas o funciones
 
  - DECLARACION CREAR LA VARIABLE
  - le dices ala computadora quiero resolver un espacio en la memoria aquí solo creas la caja todavía esta vacía
  - ejem:  edad voy a crear una variable llamada edad que guarde números enteros
 
  -  ASIGNACION DARLE UN VALOR
  -  le metes el contenido ala caja le dices en esta variable guardo un valor
  -  ejem: edad =18 en la variable edad 18 guardo el numero 18
 
  -  USO DE LECTURA LEER EL VALOR
  -  busca la variable por su nombre y usa lo que tiene dentro  lo muestra en pantalla lo suma lo compara etc.
  -  ejem print edad muestra en pantalla lo que tiene guardado la variable edad
 
  -  MODIFICACION CAMBIAR SU VALOR
  -  como su nombre lo indica  puede variar puede cambiar su contenido  cuantas veces  quieras
  -  ejem edad = 19 ahora  la variable edad ya no es 18 ahora vale  19
